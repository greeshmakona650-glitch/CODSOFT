# Movie Genre Classification

## Objective

Build a machine learning model that predicts the genre of a movie based on its plot summary.

## Dataset

Movie plot summaries and genres dataset.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* TF-IDF Vectorizer

## Algorithms Used

* Logistic Regression
* Naive Bayes
* Support Vector Machine (SVM)

## Workflow

1. Load dataset
2. Preprocess text data
3. Convert text into numerical features using TF-IDF
4. Train multiple machine learning models
5. Compare accuracy scores
6. Select the best-performing model
7. Predict genre from user input

## Result

Successfully classified movie genres using NLP techniques and machine learning models.
