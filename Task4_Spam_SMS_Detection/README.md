# Spam SMS Detection

## Objective

Build an AI model that classifies SMS messages as Spam or Ham (Legitimate).

## Dataset

SMS Spam Collection Dataset.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Natural Language Processing (NLP)

## Algorithms Used

* Logistic Regression
* Naive Bayes
* Support Vector Machine (SVM)

## Workflow

1. Load SMS dataset
2. Preprocess text messages
3. Convert text into numerical features using TF-IDF
4. Train multiple classification models
5. Compare model accuracy
6. Select the best-performing model
7. Predict whether a user-entered SMS is Spam or Ham

## Result

Successfully classified SMS messages with high accuracy and detected spam messages effectively.
