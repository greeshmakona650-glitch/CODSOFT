# Customer Churn Prediction

## Objective

Develop a machine learning model to predict whether a customer is likely to leave a service or remain a customer.

## Dataset

Bank Customer Churn Prediction Dataset.

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Algorithms Used

* Logistic Regression
* Random Forest
* Gradient Boosting

## Workflow

1. Load dataset
2. Data preprocessing
3. Handle categorical variables
4. Split data into training and testing sets
5. Train multiple machine learning models
6. Compare model performance
7. Identify important features influencing churn

## Result

Successfully predicted customer churn and identified key factors affecting customer retention.
